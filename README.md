# Coach Directory

A React app that fetches users from the JSONPlaceholder API and displays them as coach cards.

## Features

- Search coaches by name and sort by name or city.
- Select a coach to view contact, company, and address details.
- Loading, error, and empty-search states.

## Run locally

```bash
npm install
npm start
```
